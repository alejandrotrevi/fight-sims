Two golems tanked 40+ yards apart, so each player only ever hits one: simulated as a single target. Each Vitriolic Stasis puts both golems out of reach for 12-15 seconds. The Venom Coagulation slime spawns at the Breath, and groups swap sides every Stasis, so it counts for half its alive time.
