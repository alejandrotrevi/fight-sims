Fight profiles for Raidbots

Raidbots sims a target dummy by default: one boss that never moves and never brings adds. These profiles replay each boss of The Venomous Abyss the way it really goes, with its adds, intermissions, damage windows and movement. Every timing is measured from real kills on Warcraft Logs: 16 profiles from 480 kills on patch 12.1.5.

How to use it on Raidbots

  1. On Raidbots, open Top Gear, Droptimizer or Quick Sim and paste your /simc string as usual.
  2. In Simulation Options, set Fight Style to Casting Patchwerk. Plain Patchwerk deletes every raid event, so the fight would quietly turn back into a target dummy.
  3. Set Number of Bosses to 1. The profile creates the bosses itself and sets the fight length.
  4. Under Custom APL and SimC Options, tick SimC Expert Mode and paste the profile into the Script Footer box. The normal custom options box does not accept raid events.
  5. Run the sim. In the report, Raid Events should list the boss's adds and movement.

Fight Style must be Casting Patchwerk. With plain Patchwerk, Raidbots removes every raid event without a warning and you are back to a target dummy.

It works the same in Top Gear, Droptimizer and Quick Sim. With SimulationCraft on your own computer, add fight_style=CastingPatchwerk and put the profile after your character.

What a profile contains

AddsEach wave: when it spawns, how many, and how long it stays alive in real kills.
AwayTime a boss is immune, gone or out of reach.
+%Windows where a boss takes extra damage, timed from the logs and checked against real hits.
MeleeTime melee spend out of range, from gaps in real melee players' auto-attacks. Only moves melee characters.
RangedTime casters cannot hard-cast, from gaps in real casters' casting. Only moves ranged characters.
