The Coiled Altar

MythicHeroic

Zul'jan alone, then Hex Lord Malacrass alone, then both together. In the intermission Zul'jan takes double damage (Ghastly Regeneration) and Malacrass cannot be hurt. Spiteful Soulcoilers spawn across the room, and SimulationCraft has no positions, so cleave on them is optimistic.

The profile

Paste this into Raidbots' Script Footer (SimC Expert Mode), with Fight Style Casting Patchwerk and 1 boss. Step by step.

DownloadData
# The Coiled Altar (heroic) - measured fight profile for SimulationCraft / Raidbots
# Raidbots: Fight Style = Casting Patchwerk (NOT Patchwerk: it deletes raid events), Number of Bosses = 1,
#   then Custom APL and SimC Options > tick "SimC Expert Mode" > paste this into Script Footer.
# Measured from 30 heroic kills on Warcraft Logs, patch 12.1.5 (255-516 s kills).
# Kill length: median of 196 heroic kills in randomly sampled public logs = 381 s (10th pct 320, 90th 453). Set your own here:
max_time=381
vary_combat_length=0.05

# Adds: spawn = first hit on the wave, duration = first hit to last hit (median), count = median wave size
