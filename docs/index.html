How to use it on Raidbots

  1. On Raidbots, open Top Gear, Droptimizer or Quick Sim and paste your /simc string as usual.
  2. In Simulation Options, set Fight Style to Casting Patchwerk. Plain Patchwerk deletes every raid event, so the boss's mechanics would silently vanish.
  3. Set Number of Bosses to 1. The profile creates the bosses itself. Leave Fight Length alone: the profile sets it.
  4. Open Custom APL and SimC Options, tick SimC Expert Mode, and paste the profile into the Script Footer box. The normal custom-options box rejects raid events.
  5. Run the sim. Then check the report: under Raid Events you should see the boss's adds and movement, and the DPS should differ from your Patchwerk number.
The one setting people miss: Fight Style must be Casting Patchwerk. With plain Patchwerk, Raidbots strips every raid_events line and you are back to a target dummy without any warning.

It works the same in Top Gear, Droptimizer and Quick Sim, and with SimulationCraft on your own computer (add fight_style=CastingPatchwerk and the profile after your character).

What a profile contains

addsEach add wave: when it spawns, how many, and how long it actually stays alive (first hit to last hit, median over the kills).
awayWindows where a boss is immune, leaves, or is out of reach: the time its damage taken falls under 35% of normal.
+%Damage-taken windows (for example a boss taking +30% for 25 seconds), timed from the aura in the logs, with the percentage from the spell's own data.
meleeSeconds melee spend out of range, measured from gaps in real melee players' auto-attacks. These only move melee in the sim.
rangedSeconds casters cannot hard-cast, measured from gaps in real casters' casting. These only move ranged in the sim.

More on how each number is measured, and what the profiles cannot do, on the methodology page.
